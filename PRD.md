# PRD — Time Tracker

> Автоматический трекер активности для macOS.
> Локально, приватно, нативное menu bar приложение.

---

## Проблема

Нет простой, приватной, macOS-native утилиты, которая показывает:
- **Что** делал за компом в течение дня (какие приложения, вкладки, документы)
- **Сколько** времени ушло на каждое
- **Динамику** — тренды по дням/неделям

Существующие решения либо платные (Timing $10–168/г), либо отправляют
данные в облако (RescueTime), либо имеют неполированный UI (ActivityWatch).

## Решение

Electron + React приложение, которое молча записывает активность и
показывает её в наглядном виде. Данные — только локально.

---

## Целевой пользователь

Девелопер/продуктовый человек на macOS, который хочет:
- Видеть куда уходит время за компом
- Понимать динамику своей продуктивности
- Без ручных таймеров, без облака, без подписок

## Non-Functional Requirements

| Категория | Требование |
|-----------|-----------|
| **Приватность** | Все данные хранятся локально (SQLite). Ничего не отправляется в сеть. |
| **Производительность** | Опрос активного app — раз в 1 сек. UI не должен лагать при 10k+ событий. |
| **Размер** | < 150 MB (Electron overhead) |
| **Battery** | Минимальное потребление — polling 1/сек, без постоянных disk writes |
| **Autostart** | Запуск при старте системы (LaunchAgent / electron autoLauncher) |
| **Platform** | macOS (Apple Silicon + Intel). Кросс-платформа — не цель. |

## Success Metrics

- Приложение стабильно работает 8+ часов без утечек памяти
- Timeline рендерится < 100ms на день с 500+ событий
- Данные на диске < 10 MB за месяц активного использования
